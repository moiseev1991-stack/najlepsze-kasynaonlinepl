Narzędzia bukmacherskie

Kalkulator marży bukmachera — overround na zdarzeniu

Marża bukmachera (overround) to prowizja operatora „ukryta” w kursach. Wprowadź kursy dla 2 lub 3 wyników jednego zdarzenia (np. 1 / X / 2 w piłce nożnej) — kalkulator obliczy sumę prawdopodobieństw implikowanych i pokaże procentową nadwyżkę nad 100%. Im niższa marża, tym lepsze kursy dla gracza.

Jak działa ten kalkulator

Bez marży suma odwrotności kursów wszystkich możliwych wyników powinna wynosić 1 (100%). Bukmacher „dorzuca” nadwyżkę — zwykle 5–12% w piłce nożnej, 2–5% w tenisie u dobrych operatorów. Wzór: suma (1/k1 + 1/k2 + 1/k3) × 100, marża = wynik − 100%.

Wzór

prawdopodobieństwo_implikowane_i = 1 / kurs_i
suma = Σ (1/kurs_i)
overround (%) = suma × 100 − 100
fair_odds_i = 1 / (prawdopodobieństwo_i / suma)

Przykład

Piłka nożna, kursy 1 / X / 2 = 2.10 / 3.40 / 3.60. Suma prawdopodobieństw: 1/2.10 + 1/3.40 + 1/3.60 = 0.476 + 0.294 + 0.278 = 1.048 = 104.8%. Marża bukmachera = 4.8%. Fair odds (bez marży): 2.20 / 3.56 / 3.77.
